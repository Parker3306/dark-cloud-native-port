# Menus and screens: option, save/load, name registration, manual, opening book, dungeon entrance, quick change, title

Research notes for the native port (no source changes). Tags: **VERIFIED-DATA** = read from the game's initialised data / assets, **READ** = read from the decompile (`work/decomp/all_dun.c`), **INFERRED** = deduced, may be wrong. Coordinates are on the 640x448 logical screen; rects are `dst(x,y,w,h) <- src(x,y,w,h)`; pad bits (READ, consistent in every key function): `0x1000` up, `0x4000` down, `0x8000` left, `0x2000` right, `0x10` triangle, `0x20` circle (cancel / No), `0x40` cross (OK / Yes), `0x80` square, `0x1` L2, `0x2` R2, `0x4` L1, `0x8` R1, `0x100` SELECT, `0x800` START. Text glyph codes seen in the menu banks: `{fd08}` cross, `{fd06}` circle, `{fd07}` triangle, `{fd09}` square (all VERIFIED by the option help text 369 vs the key code), `{fd0a}` D-pad, `{fd00}` SELECT (INFERRED from the manual text "switch with the {fd00} button" / "Quick Character Change").

Helper added: `tools/dc/pak_ls.py <pak>` lists a pak/pac recursively. The other tools used are the existing `ui_dump.py`, `rects.py`, `menu_mes.py`, `mem.py`.

Common facts (READ): every menu screen has the same skeleton `InitXxx(...)` / `XxxKey()` / `XxxDraw()` and loads its art with `LoadFileBGMenuData("<country dir>/<file>")` = `data/commenu/a_usa/<file>`; a pak holds `<name>.img` (IM2 textures, swizzled 8 bit) + a message bank. All message banks have the format of `tools/dc/menu_mes.py` (`short[0]` entries). `AutoRepeat` masks give the key repeat (e.g. `0xf000` = the four d-pad directions, delay 30 / period 5 ticks).

## 1. OPTION menu

### 1.2 State machine (READ, `MenuOptionKey`)
State `DAT_01da8a50`: 1 = loading/fade in (art is read by `ReadBG`, alpha = 7 * tick, done after 0xc ticks), 0 = active, 2 = fade out (alpha 0x80 - 7 * tick; after 0x18 ticks `ExitMenuOption` runs and the menu returns "done").
Values are edited in a **working copy** `DAT_01da8a64[1..12]` (the snapshot for "previous config" is a second copy `DAT_01da8a94[...]`); **every exit path (cross on EXIT, circle, and nothing else) writes the working copy back** (`ExitMenuOption` stores all rows): circle does NOT cancel.
Cursor = `row*10 + col` (col 0..1, row 7 has col 0..3), `DAT_01da8a44 == 1` means the cursor is on the bottom button bar.
- cross (0x40) on a row: `value[row] = col` (picks the button the cursor is on).
- left/right: move the column; moving right off the last column goes to column 0 of the same row on the OTHER page (+/-6 rows; row 7 col 3 -> row 1 col 0), moving left off column 0 goes to the last column of the other page's row (row 1 col 0 -> row 7 col 3).
- up/down: row +/-1 inside the page (6 rows per page); down on the last row (6 / 12) enters the button bar, up on the first row (1 / 7) enters it too; in the bar up/down returns (down -> first row, up -> last row).
- any shoulder button (0xf): jump to the other page (+/-6 rows).
- button bar: cross = EXIT (fade out + commit), square (0x80) = `InitOptionFlag` (all 12 rows to default: 0, row 7 = 1), triangle (0x10) = `PrevOptionSetFunc` (restore the values as they were when the menu opened). Help text 369: `{fd08} Config completed / {fd09} return to default / {fd07} return to the previous config`.
- the help window message while a row is under the cursor = id `349 + row` (rows 1..12 -> 350..361), button bar -> 369 (`0x171`). Sound effects through `ComMenuSePlay`.

## 2. SAVE / LOAD screens

Functions (READ): `InitMenuSave` 0x21fb10, `MenuSaveKey` 0x21fed0 (driver), `DrawMenuSave` 0x2203d0, state functions `SaveMenuKey*` (table `SaveMenuFunc` at 0x293f60, 26 entries, index = state `DAT_01da8ad4`), `GetSaveMenuMsgNo` 0x222410, `SaveMenuTextureEnter` 0x222640, `DrawSaveBoard` 0x222aa0, `DrawNewFileTemplete`, `DrawSaveBoardCharaName2` 0x23cb50, `GetSaveFileInfoFromMc` 0x2154a0 (fills the slot info), `SaveToMc` 0x215b90, `LoadFromMc` 0x216240, `SaveEnableCheck` 0x223ac0, `InitExistData` 0x223940. Art `commenu/a_usa/savetex.pak` = `saveimg.img` (textures `save` 384x384, `hira`, `kata`, `alphabet` = glyph sheets for the names), `dkicon*.ico` (memory card icons, not needed), `allmenu.mes` (messages 250..299 below).

### 2.1 Entry modes (`InitMenuSave(mode, ...)`)
- mode 0 = **title "CONTINUE"** (`InitSave` 0x142b00 passes `mc_mode`): shows the file list straight (state 3, `DAT_01da8aec = 1` = LOAD), label "LOAD". After a load the menu returns to the main loop (`DAT_01da8ae8 = 1`, state 1 = fade out).
- mode 1 = **in-game menu** (town `EditMenuSelect`, dungeon `BattleMenuSelect` via `BattleMenuSaveKey`): `DAT_01da8aec = 2` = SAVE (saving is possible in town and dungeons); after a successful load it calls `EditLoad()`.
- mode 2 / 3 = **after the ending** (state 0x16 = "save cleared data": message 298 `Want to save cleared data to Memory Card (PS2)? X Yes O No`); the config clear flag `+0x38` and `GameClearFlag` are set (mode 2) or cleared.
`DAT_01da8aec`: 1 = load, 2 = save. State 2 (`ModeSelect` Save/Load chooser: up/down toggles, cross confirms, circle exits) exists but no caller reaches it in the decompile.

### 2.2 What a slot shows (READ + VERIFIED-DATA art)
**12 slots** (cursor 0..11, `SaveMenuKeyFileSelect`: up/down +/-1, no wrap; circle = back to the memory card chooser, cross = select). Slot info record `SAVEDATA_INFO` (0x38 bytes, array at 0x1da879c, built by `GetSaveFileInfoFromMc` from the loaded save buffer):
| +0x00 | int | slot exists (0 -> drawn as an empty NEW FILE board; loading an empty slot just beeps) |
| +0x04 | int | slot number (1-based) |
| +0x08 | 0x20 bytes | **Toan's name** (`GetCharaName(0)`, 16-bit codes, only the first 10 are drawn; see section 3) |
| +0x28 | float | play time in **1/60 s ticks** (`GetPlayTime`), drawn as HH:MM:SS, clamped to 21599999 ticks (99:59:59) |
| +0x2c | byte | `CDngStatusData +5` = number of characters in the party roster (1..6): that many face portraits are drawn |
| +0x30 | int | `MapNo` at save time (`CSaveData +0x1c8`): picks the location name sprite |
| +0x34 | int | sum of `QuestDungeon(0..5)` + `QuestDungeon(6)` (per-dungeon visit counters, +1 per entry: `InitDunEnterMenu` calls `QuestDungeon(dungeon, 1)`), capped 9999: printed in the "DUNGEON ... TIMES" row |
**Not shown**: gold, level, items, HP. Layout of one board (`DrawSaveBoard(info, textures, x, y, tint, alpha)`; the list uses x = 140, y = 150 - 150*selected + 150*i, i.e. boards are 135 px tall on a 150 px pitch and the list scrolls so the selected board sits at y = 150, eased `y += (target - y)/4`; non-selected states dim to 0x40):
- board `dst(x, y, 384, 135) <- save(0,0,384,135)`; header "FILE", "PLAY TIME", "DUNGEON", "TIMES" labels are part of the art.
- slot number: font B digits `src(136 + 12*d, 202, 12, 16)`, right aligned so the last digit ends at x+84 (digits placed leftwards, step 11), y+8.
- name: `DrawSaveBoardCharaName2` at (x+0x22, y+0x1c): up to 10 glyphs 22x22 (`src` from the name sheets by `GetNameTextureInfo`, see 3.3), each drawn twice (shadow +2,+2 then the glyph), the whole name is centred-compressed when longer than 175 px, `GetFontLRTumeW` kerns.
- play time: font A digits `src(136 + 12*d, 184, 12, 18)` at y+0x36: seconds tens at x+0x9c, ones at +12; minutes tens at x+0x7e; hours tens at x+0x60 (ones +12 each); colons `src(256,184,12,18)` at x+0x76 and x+0x94.
- dungeon count: font B digits right-aligned to x+0x88, y+0x52.
- location name `dst(x+0x23, y+0x63, 136, 21) <- save(((i/7)*136), ((i%7)*20 + 184), 136, 21)` for sprite index i < 14, and for i >= 14 `src(0, (i-14)%7*20 + 324)`; `i = table[MapNo]` with the 62-entry short table at 0x294070 (VERIFIED-DATA): `0->0 Norune; 1->1 Matataki; 2->2 Queens; 3->3 Muska Racka; 4->6 Moon Factory; 5-10->0; 11-13->1; 14-18->9 Brownboo; 19-20->2; 21->4 Yellow Drops; 22->10 Sun&Moon Temple; 23->4; 24-26->13 Dark Heaven Castle; 27->10; 28->9; 29-32->4; 33->1; 34->10; 35->12 Shipwreck; 36->10; 37->5 Moon Sea; 38->13; 39->12; 40->13; 41->4; 42->10; 43-45->2; 46->13; 47->4; 48-50->13; 51-59->0; 60-61->14 Demon Shaft` (sprite idx names in the `save` sheet: 0 NORUNE VILLAGE, 1 MATATAKI VILLAGE, 2 QUEENS, 3 MUSKA RACKA, 4 YELLOW DROPS, 5 MOON SEA, 6 MOON FACTORY, 9 BROWNBOO VILLAGE, 10 SUN&MOON TEMPLE, 11 GALLERY OF TIME, 12 SHIPWRECK, 13 DARK HEAVEN CASTLE, 14 DEMON SHAFT; 7, 8 are the digit rows). Maps >= 62 are out of range of the table.
- party portraits: i-th (0-based, i < count) `dst(x+0xcf + 56*(i%3), y+0x1a + 52*(i/3), 48, 49) <- save(48*i, 136, 48, 48)` (order Toan, Xiao, Goro, Ruby, Ungaga, Osmond; 3 per row, 2 rows).
- empty slot (`DrawNewFileTemplete(x, y, alpha)`): a tiled frame (corner/edge pieces `src(288,136)`, `src(320,136)`, `src(304,136)`, `src(288,168)`, ... 16x16) with the label "NEWFILE" `dst(x+0x86, y+0x35, 116, ..) <- src(268,184,116,..)`.

Message window top-left of the slot list at y ~ 0x138-0x170 depending on the state (floats in `DrawMenuSave`), hand pointer `save(352,214,32,32)` for the yes/no dialogs.

## 3. NAME REGISTRATION

Functions (READ): `InitNameRegist(chara, texblock, buf)` 0x2384a0, `NameEnterKey` 0x23a840, `NameEnterDraw` 0x239ba0, `DrawNameTemplete` 0x2390a0 (the grid), `DrawCharaNameUp` 0x238a70 (portrait + name row), `DrawCharaName`, `DrawNameRegiWaku` 0x238880, `CheckName` 0x239a40, `NameDefaultSet` 0x23c770, `GlobalNameInit` 0x238450 (all six defaults at boot), `GetNameTextureInfo` 0x2386a0, `ExitNameEnterFunc`. Art `commenu/a_usa/nameregi.pak`: `nameregi.img` (textures `nametemp` 512x512 = panels/buttons, `alphabet`, `hira`, `kata`, `charaface` 256x320 = six faces of 106x106 (2 columns x 3 rows), `window`), banks `nameregi.bin` (key-help bar, id 0 = `{fd0a} Select {fd08} Enter {fd06} Return`; the bank is installed as common bank 3 with `InitMenuMesSet(3, ...)`) and `nameregi2.bin` (ids 91, 95, 100..105; installed into the menu window with `SetBuff`).

### 3.1 Who is named, when (READ)
`NameSelect` = character 0..5 (Toan, Xiao, Goro, Ruby, Ungaga, Osmond). Toan: right after the **opening book** (`OpeningBookKey` state 4 -> `InitNameRegist(0, ...)`, same code path for the name entry as menu mode 6). Other characters: `menu_mode == 6` (`EdInitModeFinish` 0x172d30: `InitNameRegist(name_reg_chara, 0x10)`), set by the event scripts when the character joins (INFERRED: ext function name register). Result is written straight into `CSaveData +0x48 + 0x40*n` (`GetCharaName(n)`, 0x20 shorts = 0x40 bytes per name).
Screen: faces `charaface` 106x106 (chars 0-2 in the left column `src(0, 106*n)`, 3-5 `src(106, 106*(n-3))`) drawn 88x88 at (x-2, y+14) with the panel `nametemp`; the text panel title bar `nametemp(0,256,26,24)+(26,256,172,24)+(198,256,26,24)` at (x+95..), `REGISTER NAME` logo `src(0x178)`.

### 3.2 Limits, defaults, validation (READ + VERIFIED-DATA)
- **Max length 10** characters (buffer `CharaName[0..9]`, the rest of the 0x20 shorts is zeroed). Glyph codes (16 bit): `0` = empty (terminator), `0xe6` = **space** (drawn as the blank cell 68 of the alphabet sheet), `1..0x51` hiragana (sheet `hira`, cell code-1), `0x52..0xa1` katakana (`kata`, cell code-0x52), `>= 0xa2` alphabet sheet `alphabet` cell `code-0xa2` (10 columns of 22 px; `GetNameTextureInfo` returns `src(cell%10*22, cell/10*22)`, size 22x23).
